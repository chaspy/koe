macOS (Apple silicon): download Koe-{version}.dmg, drag Koe to Applications. {gatekeeper} The speech model (~1.6 GB) downloads on first launch. From v0.2.0 on, Koe offers newer releases in its menu.

Windows (preview, x64): unzip Koe-{version}-windows-x64.zip anywhere and run Koe.exe. Hold Right Alt to talk. Unsigned: click "More info" → "Run anyway". Needs the Microsoft Visual C++ runtime. Not yet widely tested.
