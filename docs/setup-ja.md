# Koe の入れ方（はじめての人向け）

Koe は、キーを押している間に話すと、その声を文字にして貼り付ける Mac のアプリです。
このページは、ふだん Mac を使っていて、ターミナルは使わない人向けです。入れてから最初の 1 回を話すところまで、10〜20 分ほどかかります（大半は音声認識モデルのダウンロード待ちです）。

必要なもの:

- Apple シリコン（M1 以降）の Mac で、macOS 14（Sonoma）以降
- 空き容量 2GB ほど（音声認識モデルが約 1.6GB）
- 最初の 1 回だけインターネット（モデルのダウンロード用。そのあとは、話した声も文字も Mac の外に送りません）

## 1. 入れる

1. [Koe の配布ページ](https://github.com/chaspy/koe/releases/latest) を開き、`Koe-<版>.dmg`（例: `Koe-0.8.0.dmg`）をクリックしてダウンロードする。`windows` と付いたファイルは Windows 用なので使いません
2. ダウンロードした dmg を開く。出てきた窓で、**Koe のアイコンを右の「Applications」フォルダへドラッグ**する
3. Finder の「アプリケーション」から Koe を開く

**「開けません」「確認できません」と出て開かないとき**: Koe はまだ Apple の確認（公証）を通していないため、初回だけ Mac が止めます。

- macOS 15（Sequoia）以降: いったん「完了」で閉じ、**システム設定 → プライバシーとセキュリティ** を開いて下へスクロールし、Koe について書かれた欄の「**このまま開く**」を押す。もう一度聞かれたら「このまま開く」を押して、Mac のパスワードを入れる
- macOS 14 以前: アプリケーションフォルダの Koe を **右クリック（または control を押しながらクリック）→「開く」** を選び、出てきた窓でも「開く」を押す

2 回目からは普通にダブルクリックで開きます。

開くと、画面右上のメニューバーに **吹き出しのアイコン** が出ます。これが Koe です。Koe には窓がなく、すべてこのアイコンのメニューから使います。
「**Koe へようこそ**」という窓が出たら「はじめる」を押します（「使い方を見る」を押すと使い方のページが開きます）。

Koe は、次に Mac にログインしたときにも自動で起動します（メニューの「ログイン時に起動」で切り替えられます）。

## 2. 許可を 2 つ出す

Koe が動くには、Mac の許可が 2 つ要ります。どちらも初めて開いたときに Mac が聞いてきます。

### マイク

「"Koe"がマイクへのアクセスを求めています」と聞かれたら「**許可**」を押します。
話した声を文字にするために使います。録音はこの Mac の中だけで文字にし、外には送りません。

### アクセシビリティ

キーを押したことに気づくのと、文字にした文を今の欄に貼り付けるのに使います。

1. 「アクセシビリティ」について聞く窓が出たら「**システム設定を開く**」を押す。Koe から「アクセシビリティの許可が外れています」という窓が出ることもありますが、はじめてのときもこの窓が出ます。そのまま「システム設定を開く」を押してください
2. 開いた **システム設定 → プライバシーとセキュリティ → アクセシビリティ** の一覧で、**Koe のスイッチをオン** にする（Mac のパスワードか Touch ID を聞かれたら入れる）
3. 一覧に Koe が無いときは、一覧の下の「**+**」を押し、アプリケーションフォルダの Koe を選んで追加し、スイッチをオンにする

オンにすると、数秒で Koe が気づきます。Koe を開き直す必要はありません。

許可が足りないうちは、メニューバーのアイコンを押したときのいちばん上の行に「アクセシビリティの許可が必要です（システム設定 > プライバシーとセキュリティ）」と出ます。この行が消えれば OK です。

## 3. 初めて話す

### 準備ができるまで待つ

メニューバーの Koe のアイコンを押すと、いちばん上の行で今の状態が分かります。

| いちばん上の行 | 意味 |
|---|---|
| 初回のみ: 音声認識モデルをダウンロード中… N%（約 1.6GB） | 最初の 1 回だけ。終わるまで待ちます（回線によって数分〜十数分） |
| モデル読み込み中… | もうすぐ使えます |
| 待機中（右⌘ を押している間だけ録音） | **使えます** |

### 話してみる

1. メモ・Slack・ブラウザの入力欄など、文字を入れたいところをクリックしてカーソルを置く
2. キーボードの **右側の ⌘（command）キーを押したまま** 話す。「ポン」と鳴ったら録音しています
3. 話し終わったら **キーを離す**。1〜2 秒で、話した文がカーソルの位置に貼り付きます

- 話し始めは「ポン」が鳴ってからにすると、最初の言葉が切れません
- 押している間にほかのキーを押すと、録音を取り消します（⌘C などのショートカットはそのまま使えます）
- ターミナルに貼ったときだけ、貼ったあとに Enter も送ります。それ以外のアプリでは貼るだけで、送信はしません

右⌘が押しにくいとき・ほかのショートカットと重なるときは、メニューの「**押して話すキー**」で右⌥・右⌃・fn に変えられます。長く話すときの使い方などは [Koe の使い方](usage-ja.md) にあります。

## うまくいかないとき

まず、メニューバーの Koe のアイコンを押して、いちばん上の行を見てください。うまくいかなかった理由がたいていそこに出ています。

- **キーを押しても何も起きない（「ポン」が鳴らない）**
  - いちばん上の行に「アクセシビリティの許可が必要です」と出ていれば、[2. 許可を 2 つ出す](#アクセシビリティ) をもう一度
  - 一覧で Koe がオンに見えるのに動かないとき（更新のあとに起きることがあります）: システム設定のアクセシビリティの一覧で Koe を選んで、下の「**−**」で消し、「**+**」でもう一度 Koe を追加してスイッチをオンにします
  - 「他のアプリがキー入力を保護中のため、右⌘を検知できません」と出ているとき: パスワードの入力欄などにカーソルがあると、Koe はキーに気づけません。別の欄をクリックしてから押してください
- **「モデル読み込み中です。少し待ってから話してください」と出る**: 準備がまだ終わっていません。いちばん上の行が「待機中」になるまで待ちます
- **「声を検出できませんでした」「声が小さく録れています」と出る**
  - マイクを口元に近づけるか、**システム設定 → サウンド → 入力** で入力音量を上げる
  - 会議中なら、会議アプリでミュートしていると Koe にも声が届かないことがあります。メニューの「**マイク**」で、会議アプリと別のマイク（Mac の内蔵マイクなど）を選んでください
- **「録音を開始できませんでした（マイクの許可を確認してください）」と出る**: **システム設定 → プライバシーとセキュリティ → マイク** で Koe をオンにします
- **「うまく聞き取れませんでした。もう一度話してください」と出る**: 周りが騒がしいか、短すぎたときに出ます。もう一度、少しはっきり話してみてください
- **文字にはなったのに貼られなかった**: 話した文はクリップボードに入っているので、⌘V で貼れます。メニューの「**最近の文字起こし（クリックでコピー）**」からも取り出せます
- **それでも直らない・遅い・おかしい**: メニューの「**診断情報を書き出す（不具合を送る用）**」を押すと、デスクトップに zip ができます。Koe を紹介してくれた人（か、Koe の問い合わせ先）に送ってください。入っているのは、版・機種・設定（秘密の値は伏せます）・動作の記録と速さです。話した文・録音・辞書の中身は入りません

Koe を止めたいときは、メニューの「終了」を押します。消したいときは、アプリケーションフォルダの Koe をゴミ箱に入れます。
