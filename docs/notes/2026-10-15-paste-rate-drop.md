# 2026-10-15 の ①入力された 91.6% の原因（BUG-1）

日次レポート（daily-2026-10-15.md）で ①入力された が 91.6%（76/83）になった。基準は 95%、前日までは 10/13 が 97.1%、10/14 が 98.5%。
`events.jsonl` と `history` を集計して原因を切り分けた（文字起こしの本文は見ていない。使ったのは数と理由の種類だけ）。

## 事実（記録から確かめたこと）

**10/15 の失敗 7 件の内訳（理由別・時刻別）**

| 時刻 | 理由 | 件数 |
|---|---|---|
| 11:17:13〜11:17:35（22 秒間） | cancelled（1 秒以上押してから別のキー）1 / no_voice 2 / hallucination 1 | 4 |
| 14:01 | hallucination | 1 |
| 16:29 | no_voice | 1 |
| 18:00 | hallucination | 1 |

- `error`（whisper-server の "Could not connect to the server"）は **0 件**だった。この失敗が出たのは 10/16 の 10:16〜10:49 の 3 件で、10:51 に `server_restart`（transcribe_connect_failed）が記録されている。直した 0.4.2 のコミットは 10/16 10:55 で、そのあと `error` は今日（10/16 夕方）まで 0 件。
- アクセシビリティ許可の外れ（候補 b）も原因ではない。許可が外れると ⌘V は黙って捨てられ、履歴には `pasted` と記録される。そのため①では成功として数えられ、①が下がる方向には効かない。代わりに `trend` の「届かず」（iTerm に貼ったのに Claude Code のセッション記録に無い発話）として出るが、10/15 の「届かず」は 1 件だけだった。`no_accessibility_at_launch` が初めて出たのは、0.5.0 を入れた 10/16 15:45。
- 7 件のうち 5 件は、30 秒以内に貼り付けに成功している（言い直して復帰した）。11:17 の 4 件のあとは 11:17:51 に貼れている。
- 11:17 の 4 件を除くと 76/79 = 96.2% で、基準を上回る。
- 10/15 は押下が 83 回で、10/12〜10/14（134〜206 回）より少ない。そのため 1 件あたり約 1.2 ポイント動く。
- 版: events に残っている最後の更新は、10/14 17:35 の 0.3.1 → 0.3.2（`update_installing`）。そのあと 10/16 までの更新は記録に無い（0.3.3 / 0.3.4 は 10/15 11:01 / 11:53 にリリースされた）。
- 今の状況: 10/16 は 100/105 = 95.2%。失敗 5 件のうち 3 件は、0.4.2 より前の `error`。残りは no_voice 1 件と hallucination 1 件で、これを除けば 98.0%。0.5.0 で増えた `no_accessibility` と `target_changed` は、今のところ 0 件。

## 結論

- 原因は (c)「それ以外」。中身は no_voice（声が拾えなかった）3 件、hallucination（雑音を文と誤認したので捨てた）3 件、押してから取り消した 1 件。(a) の whisper-server 停止と (b) のアクセシビリティは、10/15 には起きていない。
- 7 件のうち 4 件は 11:17 の 22 秒間に集中していて、残りの 3 件だけなら基準内。押下数が少ない日にまとまった失敗が重なり、比率が大きく下がった。
- 0.4.2 と 0.5.0 の修正は、no_voice と hallucination には効かない。今の版で「直った」とは言えない。ただ、これは 10/12〜10/14 にも 1 日 1〜4 件あった種類の失敗で、新しく出た不具合ではない。

## 推測（記録だけでは確かめられないこと）

- 11:17 の連続失敗は、押しては離すを短い間に繰り返したものに見える。no_voice の 2 件は 3.9 秒と 1.3 秒押して、声のある区間が 0 秒だった。hallucination は 0.57 秒。急いで言い直そうとして押し直したか、キーを押したまま話し始めるのが遅れたのだと思う。マイクの不調なら前後も失敗するはずだが、直前（11:17:18）と直後（11:17:51）は貼れている。
- 10/15 に動いていた版は 0.3.2 だと思われる。ただ、開発版を手で入れ直した場合は events に残らないため、0.3.3 / 0.3.4 だった可能性もある。どの版でも (a) と (b) の修正より前なので、結論は変わらない。

## 測り方の注意

- 0.5.0 より前は、アクセシビリティが外れて黙って貼れなかった発話が①の成功に入っていた（上の b を参照）。0.5.0 からは `no_accessibility` として記録されるので、①の失敗として数える（今回、`daily`・`misses`・`trend` で数えるようにした）。
