# Koe の使い方

Koe は、キーを押して話すと文字にして貼り付ける、Mac のメニューバーアプリです。
音声も文字も自分の Mac の中で処理し、既定では外に送りません（「使うほど賢くする（改善ループ）」か LLM 整形をオンにしたときだけ、文字が設定した送り先に出ます）。メニューバーの吹き出しのアイコンが Koe です。
何を手元に残し、何がいつ外に出るかは [Koe が扱うデータ](data-ja.md) にまとめています。
はじめて入れるときは [Koe の入れ方](setup-ja.md) を見てください。

## 基本: 押している間だけ話す

1. 文字を入れたい欄（ターミナル、Slack、ブラウザなど）にカーソルを置く
2. **右⌘を押しながら話す**（「ポン」と鳴ったら録音中）
3. **離す** → 文字になって、その欄に貼り付きます
   - ターミナル（iTerm・Terminal・Ghostty など）では、貼り付けた後に Enter まで送ります
   - それ以外のアプリでは貼るだけで、送信はしません

押している間にほかのキーを押すと、録音を取り消します（⌘C などのショートカットがそのまま使えるように）。

## 手を離して話す: 短く押す（試験中・既定はオフ）

メニューの「押し方」で「自動」を選ぶと、**右⌘を短く押して離す**（0.3 秒より短く）だけで録音が続きます。

- 話し終わったら **もう一度右⌘を押す** と、終わって貼り付けます。メニューの「録音を終えて貼る」でも終わります
- 押し続けたとき（0.3 秒以上）は、今までどおり離したところで終わります
- 録りっぱなしにならないよう、次のときは自分で止まります（「自動」だけ。「トグル」は今までどおり、もう一度押すまで続きます）
  - 押してから 8 秒、声が聞こえない: 誤って触れたとみなして、貼らずにやめます
  - 話した後、1 分黙ったまま: 終わって貼り付けます
  - 5 分たった: 終わって貼り付けます。長く話すときはロック録音を使ってください
- 録音中に他のキーやマウスを使っても止まりません

## 長く話すとき: ロック録音

1on1 のメモなど、キーを押し続けられないとき用です。

- **右⌘を素早く 2 回押す**（短く押して、0.5 秒以内にもう一度短く押す。「ポ・ポン↑」と鳴る）か、メニューの「ロック録音を始める」
- キーを押さずに話し続けます。キーボードやマウスを使っても止まりません
- **もう 1 回押す**（「ポン↑・ポン」と鳴る）と終わり、話した内容が `書類/Koe/日時.txt` に保存されて開きます。クリップボードにも入ります

## メニューで変えられること

| 項目 | 内容 |
|---|---|
| 押して話すキー | 右⌘ / 右⌥ / 右⌃ / fn。US 配列で ⌘+Space などと重なるときに変える |
| 押し方 | 「押している間だけ録音」（既定）か「押すたびに開始・終了（トグル）」。トグルでは、短く押すと録音が始まり、もう一度押すと終わって貼り付けます |
| 録音中の表示 | 設定 `recordingIndicator` をオンにすると出ます（`defaults write io.github.chaspy.koe recordingIndicator pill`。既定はオフ）。録音中・文字起こし中・失敗を小さく出します（声の大きさで揺れます）。見た目は「帯」「点」「波」から、場所は「画面の上」「文字カーソルの近く」「画面の下」から選べます |
| はじめての案内を開く | 許可・マイクの確認・キーの練習・1 回貼ってみる、を順に案内します（試験中。設定でオンにしたときだけ出ます）。改善ループをまだ決めていなければ、最後に「使うほど賢くする」の段が出て、送るものと送り先を見てから有効にできます |
| 区切りごとに改行する（ターミナル以外。Docs 向け） | 既定はオフ（設定 `lineBreaks`）。クリックでオンにすると、ターミナル以外のアプリで区切りごとに改行します。Google Docs などに長く話すとき用 |
| 用語パック | よく使う語を正しい表記で聞き取らせる辞書。開発用（developer）は最初から入っています |
| 辞書を見る… | 設定 `glossaryView` をオンにすると出ます（`defaults write io.github.chaspy.koe glossaryView -bool true`。既定はオフ）。自分の辞書・組織の辞書・用語パックの語を一覧します。自分の辞書は、Koe が使いながら覚えた語（✦）と自分で入れた語（✎）を分けて見せます。文字起こしのヒントに入りきらない語の数もここで分かります。覚えた語があると、週に 1 回だけメニューバーの下に「この 1 週間で N 語を覚えました」と小さく出ます（8 秒で消えます） |
| マイク | 「自動（既定のマイク…）」か固定のマイクを選びます。自動のときの予備は `fallbackMicName` で指定できます（下の「うまくいかないとき」を参照） |
| 使うほど賢くする（改善ループ） | 既定はオフ（設定 `improveEnabled`）。オフの間は「改善ループ: オフ（有効にすると使うほど賢くなります）」と出ます。クリックして送り先を確認するとオンになり、誤変換を自分の辞書に足していきます。既定の送り先は自分の Claude Code（コマンド `claude -p --model sonnet`）です。「改善ループで送る内容を見る…」で、次に送る内容を送らずに確かめられます。オフのまま 30 回話すと、メニューバーの下に一度だけ提案が出ます（「今はしない」なら 14 日後にもう一度。全部で 2 回まで。「改善ループの提案を出さない」で止められます） |
| 最近の文字起こし（クリックでコピー） | 貼り付けに失敗したときに、ここから取り出せます。設定 `retranscribe` をオンにすると（`defaults write io.github.chaspy.koe retranscribe -bool true`。既定はオフ）、下の段に、この 1 週間に入らなかった録音（取り消した・聞き取れなかった・文字起こしに失敗した）が出ます。押すともう一度文字起こしして、クリップボードに入れます（⌘V で貼る） |
| 自分の記録… | 設定 `statsView` をオンにすると出ます（`defaults write io.github.chaspy.koe statsView -bool true`。既定はオフ）。今日・この 7 日・この 30 日に話して入れた文字数、打つより早く済んだ時間（キーボードで 1 分に 60 文字打つとして）、続けて使っている日数と最近 5 週の使った日、Koe が直した数、文字が入るまでの速さを見せます。この Mac の履歴を数えるだけで、どこにも送りません |
| 履歴を残す期間 | 録音と文字起こしの履歴（`~/Library/Application Support/Koe/history`）は、既定で録音 14 日・文字 30 日残して消します（全体が 1GB を超えたら古い録音から）。7 / 14 / 30 / 90 日 / ずっと から選べます。ロック録音の `書類/Koe` は消しません |

## うまくいかないとき

- **声が途切れる・聞き取られない**: マイクを口元に近づけるか、システム設定 → サウンド → 入力 で入力音量を上げる（声が小さいと Koe が知らせます）
- **最初の語が切れる**: 「マイクを常時待機（頭切れ防止）」（設定 `warmMic`、既定はオン）をオンにします。キーを押す 0.5 秒前からの音を残します。キーを離したあとも 0.25 秒は録音を続けます
- **会議中に声を拾わない・マイクがミュートされている**: 会議アプリでマイクをミュートすると、Koe もそのマイクから音を取れません。メニューの「マイク」が「自動（既定のマイク…）」のときは、ハードウェアでミュートされている間だけ別の使えるマイクに切り替えます（設定 `fallbackMic`、既定はオン）。優先する予備を決めるには、Koe を終了して `defaults write io.github.chaspy.koe fallbackMicName -string "予備のマイクの名前"` を実行し、起動し直します。固定のマイクを選んでいるときは自動で切り替えません
- **許可が外れた・貼れない**: システム設定 → プライバシーとセキュリティ で「マイク」と「アクセシビリティ」を Koe に許可します。一覧で Koe がオンに見えるのに動かないとき（更新のあとに起きます。[理由](notes/signing.md#changing-the-certificate)）は、Koe を選んで「−」で消し、案内の Koe のアイコンを一覧へドラッグし直してください
- **貼られなかった**: 話し始めたアプリを前に出したままにしてください。貼る先が変わっていたときは貼らずにクリップボードに残すので、⌘V か、メニューの「最近の文字起こし（クリックでコピー）」から取り出せます
- **遅い・動かない・おかしい**: メニューの **「診断情報を書き出す（不具合を送る用）」** を押すと、デスクトップに zip ができます。それを作者に送ってください。版・機種・設定（秘密の値は伏せる）・動作の記録と速さが入ります。文字起こしの本文・録音・辞書の中身は入りません

## 更新

新しい版が出ると、メニューに「新しい版 vX があります」と出ます。押すと入れ替わって起動し直します。使い終わって落ち着いたとき（話し終えて 30 秒ほどたったとき）に 1 回だけ「今すぐ更新 / あとで」とも聞きます。「あとで」なら次の起動か 24 時間後まで聞きません。勝手に入れ替わることはありません。
