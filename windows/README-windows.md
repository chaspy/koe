# Koe for Windows（試作版）

押している間だけ録音し、離すと文字起こしして貼り付ける音声入力アプリです（押すたびに開始・終了する押し方も選べます）。
文字起こしは PC の中（whisper.cpp）で行い、音声を外部に送りません。

## インストール

1. `Koe-windows-x64.zip` を好きな場所（例: `ドキュメント\Koe`）に展開します。
2. 展開したフォルダの `Koe.exe` をダブルクリックします。
   - 署名していないため「Windows によって PC が保護されました」と出ます。**「詳細情報」→「実行」** を押してください。
3. 初回は音声認識モデル（small-q5_1、約 190MB）をダウンロードします。1〜2 分かかります。
   - タスクバー右下（`^` の中）の Koe アイコンにマウスを乗せると「モデル取得中 37%」のように進み具合が出ます。
   - 途中で止まっても、Koe を起動し直すと続きから再開します。
4. ダウンロード後、モデルの読み込みに数十秒かかります。アイコンの表示が「待機中」になれば使えます。

起動しない・「DLL を読み込めませんでした」と出るときは、Microsoft Visual C++ 再頒布可能パッケージ (x64) を入れてから起動し直してください:
https://aka.ms/vs/17/release/vc_redist.x64.exe

## 使い方

- **右 Alt を押している間だけ話します。** 離すと文字起こしして、いま前面にあるアプリに貼り付けます。
- 0.3 秒より短い押下は無視します。押している間に他のキーを押すと録音を取り消します（Alt+Tab など）。
- **押すたびに開始・終了**（メニューの「押し方」）にすると、キーを短く押して離す（0.5 秒未満）と録音が始まり、もう一度短く押すと終了して文字起こしします。
  - 録音中に他のキーを押しても取り消しません。
  - 長く押し続けたときは、これまでどおり「押している間だけ録音」と同じ動きです。
  - 録音キーを他のキーと組み合わせて押した（例: 右 Ctrl+C）ときは、開始・終了のどちらにも数えません。
- 録音開始・終了・失敗で音が鳴ります。
- ターミナル（Windows Terminal・PowerShell・cmd など）では貼り付けの後に Enter も送ります。それ以外（Teams・Slack・ブラウザ等）は貼るだけです。
- 貼り付けた文はクリップボードにも残るので、うまく貼れなかったときは Ctrl+V で貼り直せます。
- マイクは常に開いたままです（押した直後の声が切れないように）。Windows のマイク使用中の表示が出続けるのはそのためです。止めたいときは設定で `"warmMic": false` にします。
- 管理者として実行しているウィンドウには貼り付けられません（Windows の制限）。

アイコンを右クリックするとメニューが出ます:

- 状態（待機中 / 録音中 / 文字起こし中 / モデル取得中）
- 新しい版 vX があります（クリックで更新）… 新しい版が出ているときだけ出ます（下の「更新」）
- 最近の文字起こし（クリックでクリップボードにコピー）
- 押して話すキー … 右 Alt / 右 Ctrl を選べます。いま使っているキーにチェックが付きます。選ぶとすぐに切り替わり（再起動は不要）、`config.json` の `hotkey` にも保存されます
- 押し方 … 「押している間だけ録音」（既定）/「押すたびに開始・終了」。選ぶとすぐに切り替わり（再起動は不要）、`config.json` の `pressMode` にも保存されます
- モデル（速さ⇔精度） … 文字起こしのモデルを選べます。既定の small で遅いと感じたら base に、精度が欲しいときは large-v3-turbo にしてください（軽いほど速く、そのぶん誤変換が増えます）
  - small-q5_1（既定・速さと精度のバランス、約 190MB）
  - large-v3-turbo-q5_0（精度重視・遅い、約 550MB）
  - base-q5_1（とても速いが誤変換が多い、約 60MB）
  - 以前の版で使い始めた人は `config.json` に `model` が書かれているので、そのモデルのままです（既定が変わっても切り替わりません）。small にしたいときはこのメニューで選んでください
  - はじめて選んだモデルはダウンロードします（進み具合はアイコンにマウスを乗せると出ます）。終わると自動で切り替わり、`config.json` の `model` にも保存されます
- 速さ優先（短い発話を速く。精度が少し落ちることがある。turbo では効きません） … 既定オン。話した長さに合わせた枠で文字起こしするので、数秒の発話が速くなります（オフにすると毎回 30 秒ぶんの枠で処理します）。large-v3-turbo は枠を縮めると文字が出なくなるため、オンでも常に 30 秒ぶん全体で処理します。選ぶとすぐに切り替わり（再起動は不要）、`config.json` の `audioCtx` にも保存されます（オン `"auto"` / オフ `0`）
- 診断情報を書き出す（送る用） … デスクトップに `Koe-diagnostics-<日時>.zip` を作って、エクスプローラーで表示します（下の「不具合のときに送ってほしいもの」）
- ログのフォルダを開く
- 設定ファイルを開く
- 更新を確認 … 新しい版が出ていないか、いま確かめます（下の「更新」）
- Koe のバージョン（例: `Koe 0.1.1 (f2db111)`）
- 終了

## 速さの目安

GitHub Actions の Windows（AMD EPYC 7763・2 コア・GPU なし）で測った結果です（詳しくは `bench/results.md`。音声は合成音声）。

- **small-q5_1 ＋ 速さ優先（既定）が、速さと精度のバランスがいちばん良い**結果でした。30 秒ぶん全体で処理するより 3〜5 倍速く（1 回 4〜7 秒。全体だと 16〜22 秒）、一致率は 0.91〜1.00 でした。
- large-v3-turbo は枠を縮めると文字が出なくなったため、速さ優先がオンでも全体で処理します。精度は高いものの、2 コアでは 1 回 70 秒以上かかりました。
- base は速いものの、短い発話で誤変換が目立ちました。
- コアの多い PC（例: 12 スレッド）ではこれより速くなります。

## 更新

Koe は起動時と、その後 24 時間ごとに、公開版（GitHub Releases）に新しい版が出ていないかを確かめます。
アイコンのメニューを開いたときも、前に確かめてから 1 分以上たっていれば確かめ直します（メニューはすぐ開き、確認は裏で行います）。
新しい版があると、メニューに「新しい版 vX があります（クリックで更新）」が出ます。

- いますぐ確かめたいときは、メニューの「更新を確認」を押します。新しい版が無ければ「最新です（vX）」と出ます。
- 確かめるときは GitHub の API ではなく、リリースのページ（`https://github.com/<repo>/releases/latest` の転送先）を見ます。会社など、同じ回線から大勢が使っても API の回数制限（ログインなしで 1 時間 60 回）にかかりません。
- 新しい版が出ていても、Windows 用の zip がまだ上がっていなければ更新の項目は出ません（上がったあとの確認で出ます）。

- クリックすると新しい版をダウンロードして、Koe を終了し、展開したフォルダのファイルを入れ替えてから起動し直します（数十秒かかります）。
- 録音中・文字起こし中は更新できません。終わってからもう一度押してください。
- 入れ替えるのは Koe を展開したフォルダの中だけです。設定・辞書・履歴・モデル（`%APPDATA%\Koe` と `%LOCALAPPDATA%\Koe`）には触りません。展開したフォルダに自分で置いたファイルも消しません。
- うまくいかなかったときはメッセージが出て、リリースのページがブラウザで開きます。zip をダウンロードして、いまの Koe のフォルダに上書きで展開してください。入れ替えの記録は `%LOCALAPPDATA%\Koe\update.log` に残ります。
- 確かめたくない場合は設定で `"updateCheck": false` にします（起動時・24 時間ごと・メニューを開いたときの確認をしなくなります。「更新を確認」を押したときだけ確かめます）。

## 設定（`%APPDATA%\Koe\config.json`）

メニューの「設定ファイルを開く」でメモ帳が開きます。保存後、Koe を終了して起動し直すと反映されます（録音キーはメニューの「押して話すキー」からなら再起動なしで切り替わります）。

| キー | 既定 | 意味 |
|---|---|---|
| `hotkey` | `"ralt"` | 録音キー。`"ralt"`（右 Alt）か `"rctrl"`（右 Ctrl） |
| `pressMode` | `"hold"` | 押し方。`"hold"`（押している間だけ録音）か `"toggle"`（押すたびに開始・終了） |
| `model` | `"ggml-small-q5_1.bin"` | モデルのファイル名（`%LOCALAPPDATA%\Koe\models` 内）か絶対パス。`"small-q5_1"` のような短い名前も可 |
| `threads` | `0` | 文字起こしに使うスレッド数。`0` は自動（論理プロセッサ数、最大 16） |
| `audioCtx` | `"auto"` | 文字起こしの枠の大きさ。`"auto"` は話した長さに合わせる（短い発話が速い。30 秒以上は全体）、`0` は毎回 30 秒ぶん全体（遅いが元の精度）、数値は固定（1 秒 = 50、最大 1500）。メニューの「速さ優先」で `"auto"` / `0` を切り替えられます。large-v3 系のモデルでは常に `0` |
| `temperatureFallback` | `false` | うまく読めない区間を条件を変えて読み直すか。`true` にすると精度が少し上がることがありますが、遅くなります |
| `enabledPacks` | `["developer"]` | 使う用語パック（`packs\*.txt` のファイル名） |
| `packSources` | `[]` | 共有の用語パックの取り込み元。例 `["gh:owner/repo/path/pack.txt"]`（1 日 1 回、`gh` CLI で取得） |
| `autoEnter` | `true` | ターミナルで貼り付け後に Enter を送るか |
| `enterApps` | ターミナル各種 | Enter を送るアプリの exe 名 |
| `sounds` | `true` | 効果音 |
| `warmMic` | `true` | マイクを開いたままにする |
| `saveHistory` | `true` | 録音と文字起こしを 7 日分保存する |
| `updateCheck` | `true` | 新しい版が出ていないか確かめる（起動時、24 時間ごと、メニューを開いたとき〔前回から 1 分以上たっていれば〕） |
| `updateRepo` | `"chaspy/koe"` | 新しい版を探す GitHub のリポジトリ（`owner/repo`） |

## 用語の辞書

- 個人の辞書: `%APPDATA%\Koe\glossary.txt`（1 行 1 語。タブの後に誤変換された形を `／` 区切り）
- 自作の用語パック: `%APPDATA%\Koe\packs\*.txt`（`enabledPacks` に名前を入れると有効）
- 書き方は同梱の `CONTRIBUTING.md` を見てください。
- `%USERPROFILE%\.claude` があれば、Claude Code 向けの誤変換メモ（`koe-voice-glossary.md`）をそこに書き出します。

## 不具合のときに送ってほしいもの

**遅い・動かないときは、メニューの「診断情報を書き出す」でできた zip を送ってください。** デスクトップに `Koe-diagnostics-<日時>.zip` ができます。中身は次のとおりで、録音した音声と文字起こしの中身は入りません（設定のうち key / token / secret / password を含む項目の値は `***` に置き換えます）。

- `diagnostics.txt` … Koe と Windows のバージョン、CPU 名、論理プロセッサ数、メモリ、モデル、スレッド数、押し方、録音キー、用語パック、その他の設定
- `koe.log` の最後の 2000 行、`whisper-server.log` の最後の 500 行、`update.log`（あれば）

文字起こしが遅いときは、`koe.log` の `whisper_ok ms=... audio_sent=...s ms_per_audio_s=... audio_ctx=...`（音声 1 秒あたりにかかったミリ秒と、使った枠の大きさ。`0` は 30 秒ぶん全体）と、`whisper_server system_info: ...`（CPU が使える命令 AVX / AVX2 など）を見ると原因の見当がつきます。

zip を作れないときは、`%LOCALAPPDATA%\Koe` フォルダ（メニューの「ログのフォルダを開く」）から:

1. **`koe.log`**（必須）… キーの押下・録音の長さ・音量・文字起こしにかかった時間・貼り付け・エラーの記録と、起動時の CPU 名・メモリ・スレッド数です。押したキーそのものは、録音キーと「録音中に押されたキー」以外は記録しません。文字起こしの中身も記録しません（文字数だけ）。
2. **`whisper-server.log`** … 起動しない・文字起こしに失敗するとき
3. 必要なら `history\<日付>\` の該当する `.json`（文字起こし結果）と `.wav`（録音）。声が入っているので、送ってよいものだけにしてください。

あわせて「何をしたら（どのアプリで、どのくらい話したら）どうなったか」と、おおよその時刻を書いてください。

## ファイルの場所

| 場所 | 中身 |
|---|---|
| Koe を展開したフォルダ | `Koe.exe`、`whisper-server.exe` と DLL、`packs\`、`assets\` |
| `%APPDATA%\Koe` | `config.json`、`glossary.txt`、`packs\` |
| `%LOCALAPPDATA%\Koe` | `koe.log`、`whisper-server.log`、`update.log`、`models\`、`history\` |

アンインストールは、Koe を終了してから上の 3 つのフォルダを消すだけです。
